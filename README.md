# SAR-processing

This repository contains scripts and miniprojects for Synthetic Aperture Radar (SAR) data processing. Each miniproject demonstrates specific techniques for working with SAR data.

## Projects
1. **[Reduce Speckle Noise](01-Reduce-Speckle-Noise)**  
   A Python application with a Tkinter GUI for applying mean or median filters to GeoTIFF images, commonly used in SAR processing to reduce speckle noise.

2. **[Sentinel-1 SAR Batch Processor](02-Sentinel-1-SAR-Batch-Processor)**  
   A graphical interface (Tkinter) for automated preprocessing (python, esa_snappy) of Sentinel-1 SAR imagery.
